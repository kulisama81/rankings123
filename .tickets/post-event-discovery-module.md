# Post-event What's Next discovery module for retention

**Context:** WC Finals is TODAY (July 19). After final whistle (~6PM ET), users searching 'World Cup 2026 results' need to discover what's live NOW (TdF final week, tennis) or bounce forever. Homepage shows 70% bounce vs 0% for sport pages. 2026 retention research (gr8.tech, Kambi): First 48 hours post-event are critical. Create post-event discovery module for archived tournament pages.

## Acceptance Criteria

- PostEventDiscovery component for archived pages | - Shows 2-4 Live NOW cards to other sports | - Per-sport accent colors, pulse badges | - Gamification hook: Followed 32 teams? Track 500+ players | - Mobile-first horizontal scroll | - Auto-updates based on event calendar | - Analytics tracking: post_event_discovery_click | - Visual: bold heading, card grid, accent glow hover, entrance animation | - Placement: below results, above footer
