# Mobile-optimized table UX patterns

Improve mobile table UX across all sports. Analytics: 39% mobile traffic, cycling pages had 100% bounce (now fixed but UX needs polish). Options: horizontal scroll with scroll shadows, column prioritization (hide less important cols on mobile), sticky rank column. First principles: CX FIRST. 39% of users are on mobile; poor mobile UX = lost traffic. One bad experience = user never returns.

## Acceptance Criteria

Mobile table patterns for ATP/WTA/World Cup/Cycling. Horizontal scroll with visual scroll indicators OR column hiding with expand. Touch-friendly (no accidental taps). Tested on iPhone/Android. Mobile bounce rate measured. Effort: MEDIUM. Impact: HIGH (39% of users).
