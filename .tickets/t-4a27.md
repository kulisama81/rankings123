# World Cup: "No upcoming fixtures" placeholder shows when fixtures exist

## Bug Report

**URL:** https://rankings123.com/world-cup

**Severity:** P2 (Medium) — UI consistency bug affecting user confidence

**Type:** Data consistency bug — placeholder text contradicts actual content

**Description:**
The World Cup page displays "No upcoming fixtures scheduled" and "Check back as the tournament schedule is announced" in the Schedule section, WHILE SIMULTANEOUSLY showing actual match content throughout the page:
- "Today's Matches" section with completed fixtures (e.g., Argentina 3-1 Switzerland)
- Full Round of 32 knockout bracket with team matchups
- Complete group standings showing matches have been played
- Match links to individual match detail pages

This creates a confusing contradiction where the system claims no fixtures exist while displaying extensive tournament results and fixtures.

**Reproduction Steps:**
1. Visit https://rankings123.com/world-cup
2. Scroll to the Schedule section
3. Observe "No upcoming fixtures scheduled" placeholder text
4. Note that the same page shows:
   - "Today's Matches" section with actual matches
   - Knockout bracket with R32 matchups
   - Group standings with played matches
   - Links to match detail pages

**Expected Behavior:**
- If fixtures exist, the Schedule section should display them (upcoming matches list/calendar)
- If no upcoming fixtures exist, the placeholder is fine, but it should be accurate
- Placeholder text should NOT appear when actual fixtures are available elsewhere on the page

**Actual Behavior:**
- "No upcoming fixtures scheduled" placeholder shows
- Page ALSO shows Today's Matches, bracket, group standings, and match links
- Creates data consistency issue and user confusion

**Impact:**
- Undermines trust in data accuracy and site reliability
- Users see contradictory information on the same page
- Suggests broken data feed or incomplete implementation
- Violates consistency principle (placeholder should not show when content exists)

**Possible Root Causes:**
- Placeholder is hardcoded and not conditionally rendered based on actual fixture availability
- Schedule section queries different data source than Today's Matches section
- Fixture/match data exists but Schedule component doesn't receive or display it
- Conditional rendering logic missing or broken (should hide placeholder when matches exist)
