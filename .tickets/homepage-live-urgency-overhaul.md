# Homepage live urgency overhaul — fix 70% bounce crisis

CRISIS: Homepage bounce 70% vs 0% for sport pages (analytics July 19). Users can't tell what's LIVE NOW. Root cause: passive design, equal-weighted sport cards, no urgency. 2026 pattern (SofaScore, FlashScore): LIVE NOW prominence, scores updating, countdowns. Redesign homepage hero + cards to scream LIVE.

## Acceptance Criteria

- Dynamic live headline (WC Final LIVE, TdF Stage LIVE, 24 tennis matches) | - Large pulse dot animation (8px, accent) | - Countdown timer for marquee events | - Sport card hierarchy: Live cards float top, enlarged, glow | - Live score tickers in cards | - Hover peek: top 3 rank changes mini-table | - Mobile-first: 2-line headline, full-width cards | - Zero layout shift, skeleton states | - Respect prefers-reduced-motion
