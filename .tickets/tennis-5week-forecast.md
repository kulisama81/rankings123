# Tennis 5-week ranking forecast (parity with live-tennis.eu)

Add 5-week ATP/WTA ranking forecast showing projected ranking 5 weeks ahead based on points to defend. Live-tennis.eu has this as a signature feature. Differentiation opportunity: most tennis sites show only current or next-week rankings. Forecast helps fans understand upcoming ranking battles and engages during non-tournament weeks.

## Acceptance Criteria

✓ /atp-live/forecast and /wta-live/forecast routes exist
✓ Show ranking projections for next 5 weeks
✓ Based on current points + points to defend schedule
✓ Highlight ranking battles (who could overtake whom)
✓ Update weekly as tournaments complete
✓ SEO optimized (meta tags, OG)
✓ Mobile responsive
✓ Source flag visible
