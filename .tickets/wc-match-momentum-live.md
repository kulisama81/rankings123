Live match momentum indicators for WC (semifinals/final) - differentiation

## Acceptance Criteria

Live match pages show momentum indicators (possession %, shots, dangerous attacks), visual momentum bar, updates every 30-60s from ESPN API, key events timeline (goals/cards/subs), match impact context (winner faces X in next round), test during semifinals

## Differentiation - Beyond Basic Scoreboards

**Competitor gap:** Most sites show score. Few show MOMENTUM and match flow visually.

**ESPN data available:** Possession %, shots, shots on target, attacks, dangerous attacks - all in their match API.

**User need:** "Who's dominating?" "Is this comeback real or lucky?" = momentum questions basic scores don't answer.

**Timing:** Semifinals (July 14-15) + Final (July 19) = 3 matches to showcase this feature at peak attention.

**First Principles:** Sports fans want to UNDERSTAND the match, not just see score. Momentum = match story.
**Effort:** MEDIUM (ESPN API + calculation + visualization)
**Impact:** HIGH (differentiation, engagement, perfect for live betting context)
**ROI:** HIGH (differentiator that ships for tournament climax)
