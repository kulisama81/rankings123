# Tennis player profile pages (top 20 ATP/WTA)

SEO LONG-TAIL ENGINE: Player pages = THE traffic multiplier. 'Jannik Sinner ranking', 'Carlos Alcaraz stats' = 10K+ searches/month EACH for top players.

PARITY: live-tennis.eu has player breakdowns. We don't. Each player page = indexable SEO asset.

SCOPE: Start with top 20 ATP + top 20 WTA (40 pages). Proves the pattern, captures highest-volume searches.

CONTENT: Rank, points, tournaments played, points breakdown (current + defending), career high, form (last 5), next tournament.

REVENUE: Player pages = perfect betting affiliate context ('Sinner vs Alcaraz odds →').

ROI: 9/10 — SEO multiplier (40× indexable pages), Phase 1 parity, proven search demand, reusable template.
