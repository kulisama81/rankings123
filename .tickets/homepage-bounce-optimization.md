# Homepage Bounce Rate Optimization (83.9% → <60%)

Analytics show homepage bounce rate = 83.9% (very high). Users land and leave without clicking. Improve: clearer value prop, stronger CTAs to rankings/tournaments, visual hierarchy, above-fold engagement hooks (live scores ticker, countdown timers).

## Acceptance Criteria

- Add live scores ticker for in-progress matches (if any) above-the-fold
- Strengthen hero section: 'Live Rankings Updated Every 20 Seconds' value prop
- Clear CTA buttons to ATP/WTA/World Cup (not just nav tabs)
- Add 'What's New' section highlighting recent updates
- Reduce clutter: streamline footer, consolidate links
- A/B test: measure bounce rate before/after (target <60%)
- Mobile optimization (26% mobile traffic)
- Builds green, ESLint clean, core features intact
- Post-deploy: monitor GA4 bounce rate for 7 days

## Notes

**2026-07-24T13:51:40Z**

ROI (First Principles): Engagement = 83.9% bounce means losing 84% of homepage visitors. Revenue = bounce = zero pageviews = zero ads. Reducing bounce to 60% = +24% pageviews = +24% revenue. User need = immediate clarity on value. CX = homepage is first impression. Effort = Medium (UX redesign, A/B testing). ROI = VERY HIGH (revenue multiplier via engagement).
