Audit live-tennis.eu, FlashScore, SofaScore, ATP/WTA official for features we lack. Phase 1 = match their core features. Document gaps: doubles, race rankings, historical rankings, head-to-head detail, points breakdown. Create/update tickets with data sourcing plans.

## Acceptance Criteria

1. List competitor features across 5 sites. 2. Map to our existing tickets (head-to-head, rank-history, doubles, points-defend). 3. Identify NEW gaps (features we haven't ticketed). 4.
