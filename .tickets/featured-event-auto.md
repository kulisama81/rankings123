# Dynamic featured event: promote the most relevant live event, auto-dismiss when over

The homepage still features the World Cup, which ENDED ~July 19 — stale/wrong. Build a dynamic 'featured event' module that promotes the most relevant CURRENT/upcoming event to the hero based on real status/dates, and automatically DEMOTES/removes it once it's over (finished events drop from the hero to an archive/results link, never shown as live). Data-driven from each sport's event status + dates — no hardcoded event. Immediate effect: remove the finished World Cup from the landing hero and feature the next most relevant live/upcoming event (e.g. current tennis events / US Open build-up).

## Acceptance Criteria

Homepage hero features the most relevant live/upcoming event, chosen dynamically from real event status/dates; finished events (e.g. World Cup now) are auto-removed from the hero (not shown as live); updates automatically as events start/end; no hardcoded 'World Cup'; live-verified.
